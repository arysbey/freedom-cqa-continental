## Реализовано

- Evidence Desk: фильтры языка, канала, группы и наличия оценки; сортировка, поиск ID и фрагмента транскрипта, навигация клавиатурой. В центре подсвечиваются точные цитаты и проверенный диапазон; справа — версия, шкала, N/A, вес, объяснение, происхождение и пересмотр.
- Отдельный контур слепой человеческой валидации. Эталонные ответы не заполняются моделью. Частичная разметка сохраняется, уже подтверждённые ответы неизменяемы; новые ответы можно добавлять только к нерешённым критериям. Модельные ответы по ещё не проверенным критериям скрыты. Семантическая проверка доказательств хранится отдельно.
- Аудиопрокси и локальный закрытый кеш. Исходный GET возвращает HTML-плеер; сервер извлекает подписанный медиаресурс, проверяет источник и формат, отдаёт локальный MP3 с HTTP 206. Подписанные URL в браузер не передаются.
- Полная локальная ручная оценка, черновик, точные цитаты, диапазоны, детерминированный итог, апелляция и постоянная история. `human_entered`, `manual_demo` и `live_validated` обозначаются раздельно. Ручной ввод не вызывает модель и не становится автоматически человеческим эталоном.
- GET по произвольному group_id и локальный JSON-импорт через UI. Неизвестные источники по умолчанию закрыты для AI. Уполномоченный человек может явно разрешить Free-tier обработку конкретной неизменяемой версии синтетического чата без изменения кода. Разрешение связано с хешем всего источника; звонки и записи с аудио не допускаются независимо от подтверждений. Фактических разрешений в рабочей базе 0.
- Постоянный журнал попыток: успешный результат либо явная ошибка, время, доступный usage. Ошибка не превращается в нулевую/идеальную оценку.
