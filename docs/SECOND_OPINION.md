# Частная вторая AI-оценка

Этот путь предназначен для поиска расхождений между двумя AI-оценками. Он не создаёт человеческие эталоны, не измеряет точность и не участвует в официальном экспорте. Название сервиса и модели в ответе — неподтверждённое заявление отправителя, без проверки авторства.

Экспорт читает SQLite только для чтения: frozen manifest, шесть development-источников и точный `official-v1`. Holdout, Gemini-ответы, человеческие решения, апелляции и история в пакет не попадают. Полные исходные реплики сохраняются с исходными ролями, временем, языком, каналом, стабильными ID и индексами от1. Подписанные/обычные URL, распознаваемые credentials, реальные звонки и аудио блокируют экспорт целиком; скрытое сокращение текста не применяется.

```powershell
node --import tsx scripts/export-second-opinion.ts
```

Появится новый закрытый каталог `private/second-opinion/<timestamp>/` с `bundle.json`, `review.md` и `response-template.json`. Ответы в шаблоне — `null`; это незаполненные поля, не оценки. Передайте эти файлы ChatGPT вручную. Никакой API-вызов команды не делают. Попросите заполнить шаблон без изменения хешей/источников; если модель неизвестна, так и укажите. Не отправляйте `private/cqa.sqlite`, `.env`, человеческую разметку или другие файлы.

```powershell
node --import tsx scripts/import-second-opinion.ts --bundle private/second-opinion/<timestamp>/bundle.json --input private/second-opinion/response.json
```

Импорт проверяет хеш пакета, версии и полноту источников в текущей SQLite, точный официальный чек-лист, полный набор случаев/критериев, шкалы и N/A, 1-based индексы, точные цитаты, диапазоны и доказательство от оператора для положительного критического флага. Семантическая истинность решения такой проверкой не устанавливается. Пустой шаблон не импортируется.

Результат записывается только в отдельный `private/second-opinion/ledger.sqlite`, таблицу `ai_second_opinions`. Основная SQLite не меняется. История append-only; повторный `requestId` с тем же содержимым возвращает прежнюю запись, с изменённым — отклоняется. Provenance всегда `ai_second_opinion`, `humanGroundTruth=false`, `eligibleForOfficialExport=false`.

Команда также показывает путь к частному JSON-отчёту `private/second-opinion/reports/<id>.json`: там находятся импортированные решения, отдельные баллы, источники и сравнение по каждому критерию. Повторный импорт сохраняет прежний снимок сравнения; изменение Gemini-истории не переписывает прошлый отчёт.

Частное сравнение выбирает первый подходящий настоящий Gemini3.1 Flash Lite Free результат `official-v1` для той же версии источника с проверенными доказательствами и детерминированным баллом. Хранит ID/config результата, решения по критериям, разности баллов/критического флага и категории N/A. Это расхождения AI-vs-AI, а не ошибки против gold или human accuracy/MAE. Отсутствующий Gemini-результат отражается `null`.

Файлы под `private/` не публикуются. Команды поддерживают `--db` для изолированной копии; экспорт также `--manifest` и `--out`, причём вывод разрешён только внутри `private/`. Существующий пакет не перезаписывается. Архитектура приложения, модель, official definitions и scoring не меняются.
