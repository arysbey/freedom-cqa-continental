# Официальные результаты Continental

Организаторы требуют `dev/results.json` с65 исходными DEV ID и `prod/results.json` с10 настоящими контрольными ID. Папка не содержит исходных транскриптов, аудио, ключей или человеческих эталонов.

DEV-файл может содержать честные ошибки для ещё не оценённых записей. Наличие65 строк не означает65 успешных оценок и не доказывает качество против Ground Truth. Перед отправкой выполните строгую проверку по фактически импортированным источникам.

PROD не подменяется учебными ID. Файл создаётся после выдачи настоящего набора; программная репетиция хранится под игнорируемым `tmp/`. Оба настоящих файла должны попасть в утверждённый публичный remote до официального стоп-кода. До успешного push и проверки remote сдача не подтверждена.

Команды и действия: [порядок последнего часа](../docs/PROD_RUNBOOK.md).
