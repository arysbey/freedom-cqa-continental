# Freedom CQA

Локальная система оценки работы оператора по изменяемому чек-листу. React + TypeScript, Fastify, SQLite (`node:sqlite`), официальный `@google/genai`. Вход и регистрация для демо не нужны.

## Запуск

Нужны Node.js 24+ и pnpm. Из корня проекта:

```powershell
pnpm install --store-dir .pnpm-store --config.enable-global-virtual-store=false --config.node-linker=hoisted --config.package-import-method=copy
Copy-Item .env.example .env
# Откройте .env в локальном редакторе и заполните конфигурацию.
pnpm build
pnpm start
```

Интерфейс: http://127.0.0.1:3001. Сервер привязан только к localhost. При разработке `pnpm dev` перезапускает сервер, а `pnpm exec vite` запускает frontend с API proxy. Для проверки основного сценария используется production build и реальный backend.

В этой рабочей папке зависимости уже установлены. Без pnpm в PATH:

```powershell
node node_modules/vite/bin/vite.js build
node node_modules/tsx/dist/cli.mjs server/index.ts
```

## Ключ и бесплатная модель

1. Создайте ключ в [Google AI Studio](https://aistudio.google.com/apikey) в проекте **Free tier без подключённого платного биллинга**.
2. Откройте локальный `.env` в редакторе. Впишите `GEMINI_API_KEY=...` и после проверки проекта `GEMINI_FREE_TIER_CONFIRMED=true`. Уже заданный ключ окружения имеет приоритет.
3. Не отправляйте ключ в чат, не вводите его командой с сохранением в history и не используйте префикс `VITE_`. `.env`, `.env.local`, база и отчёты исключены из Git.
4. Выполните `pnpm models`. Получение списка моделей не доказывает квоту или тариф проекта. Активные лимиты проверяются в AI Studio.

По умолчанию выбран `gemini-3.1-flash-lite`: доступность подтверждена настоящими структурированными оценками. Первая настоящая оценка также получена через `gemini-3.8-flash`. Выбор итоговой конфигурации и выявленные смысловые ошибки описаны в `docs/MODEL_NOTES.md`. Free mode подтверждается пользователем: model ID сам по себе не гарантирует бесплатный проект. Автоматической активации биллинга, смены на платную модель и платного fallback нет.

Используется официальный режим рассуждений LOW для Gemini 3.x и таймаут до 120 секунд. В ходе проверки зафиксированы HTTP 504 у Gemini 3.8 и HTTP 404 у Gemini 2.5, хотя последняя присутствовала в model listing. Наличие ID в каталоге не гарантирует успешной генерации. Ошибки не превращаются в оценки.

Бесплатный Gemini может использовать отправленный текст для улучшения продуктов. Сервис пропускает только точные разрешённые синтетические DEV-чаты по хешу содержимого. Реальные звонки, неизвестные группы, аудио и производные данные внешней модели недоступны. Телефоны, email, длинные ID и URL маскируются перед запросом; цитаты восстанавливаются только локально и повторно проверяются. Ключ передаётся исключительно серверному SDK.

Официальные источники: [модели](https://ai.google.dev/gemini-api/docs/models), [тарифы](https://ai.google.dev/gemini-api/docs/pricing), [SDK](https://ai.google.dev/gemini-api/docs/libraries), [JSON schema](https://ai.google.dev/gemini-api/docs/structured-output), [условия](https://ai.google.dev/gemini-api/terms), [квоты](https://ai.google.dev/gemini-api/docs/rate-limits). Каталог сверялся 07.11.2026; тариф и квоты могут измениться.

## Импорт и первая оценка

Подписанную GET-ссылку организатора храните только в серверном `CQA_ORGANIZER_URL` в `.env`. Не включайте её в README, скриншоты, клиентский код или логи.

```powershell
pnpm import:dev
pnpm evaluate:first
# Другая группа использует тот же серверный endpoint:
pnpm import:dev --group CONTROL_GROUP_ID
# Локальный официальный JSON, если endpoint временно недоступен:
pnpm import:dev --file 'C:\path\to\dev.json'
```

Эквиваленты без pnpm: `node node_modules/tsx/dist/cli.mjs scripts/import-dev.ts` и `node node_modules/tsx/dist/cli.mjs scripts/evaluate-first.ts`.

Новая группа импортируется без изменения кода. Её внешняя обработка остаётся запрещённой до отдельного подтверждения происхождения и разрешения данных. Исходные роли, тексты, порядок, одинаковые timestamps сохраняются; сообщение имеет ID от версии разговора и позиции. Повторный импорт не удаляет старые оценки.

## Официальный расчёт

Чек-лист находится в `src/data/official-checklist.json`. C1–C7 имеют общий вес 100, C8 — независимый флаг. YES даёт полный вес; NO — 0. Шкальный вклад: `weight * answer / scaleMax`. N/A исключается из знаменателя. Итог: `100 * sum(contributions) / sum(applicableWeights)`, округляется до двух знаков только в конце. При отсутствии применимых весов итог `null`. Секции нормализуются по собственному применимому весу.

Расчёт выполняется точными рациональными числами в коде. Модель интерпретирует правила и предлагает ответы; баллы не вычисляет. Историческая оценка привязана к неизменяемым версиям разговора и чек-листа.

## Интерфейс и пересмотр

Выберите диалог, чек-лист и запустите оценку. Ссылки в объяснениях фокусируют исходные реплики. Для N/A показаны причина и подтверждающая цитата либо диапазон; для пропущенного действия обязателен проверенный диапазон. Флаг грубых ошибок выводится отдельно.

В разделе «Чек-листы» можно создать новую конфигурацию, добавить, изменить или удалить критерий, его смысл, шкалу, вес, раздел и N/A без изменения кода. При сохранении создаётся новая версия.

В сохранённой оценке режим «Заявитель» подаёт апелляцию; «Проверяющий» подтверждает или меняет ответ с причиной. Исходный результат сохраняется, итог пересчитывается без дополнительного обращения к модели. Роли демонстрационные, без production-авторизации.

## Проверки

```powershell
pnpm typecheck
pnpm lint
pnpm test
pnpm build
node node_modules/tsx/dist/cli.mjs scripts/browser-smoke.ts
node node_modules/tsx/dist/cli.mjs scripts/browser-live-dynamic.ts
```

Browser smoke использует установленный Google Chrome, локальный сервер и настоящий импорт. Путь браузера можно переопределить через `CQA_BROWSER_EXECUTABLE`; иначе используется Chrome на Windows или Playwright-managed Chromium (установите `pnpm exec playwright install chromium`). Порт берётся из серверной конфигурации.

`browser-live-dynamic` дополнительно создаёт критерий через форму, делает настоящий запрос к модели и проверяет апелляцию с демонстрационным изменением/восстановлением ответа. Он требует ранее сохранённой оценки official-v1 и расходует бесплатную квоту. Browser-проверки не подменяют live AI тестовыми ответами. Программные двойники модели присутствуют только в unit-тестах; успешный unit-тест не является доказательством качества модели.

## Границы готовности

Статус фактических проверок и ограничения — в `docs/PROGRESS.md`. Диагностические ответы модели и результаты находятся только в `private/`, в открытый репозиторий не включаются. Публичная публикация и отправка ссылок организаторам в рамках текущего запуска не выполнялись.

Контрольный набор открывается через 23 часа после официального старта, стоп-код — через 24. Абсолютное время старта в исходных документах не указано; дедлайн по календарю не выдумывается.
